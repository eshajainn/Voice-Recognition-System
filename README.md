VOXIFY — Voice • Text • Translation AI System

📌 Overview

VOXIFY is an AI-powered web application that performs:

🎤 Speech-to-Text Conversion
🌍 Multilingual Translation
🔊 Text-to-Speech Conversion

The system allows users to:

Upload audio files
Speak directly using a microphone
Convert speech into text
Translate text into multiple languages
Convert text back into speech

The project is developed using Python, Flask, JavaScript, and Speech Recognition APIs with a modern and responsive UI.


Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/your-username/VOXIFY.git
2️⃣ Navigate to Project Folder
cd VOXIFY
3️⃣ Install Dependencies
pip install -r requirements.txt
4️⃣ Run the Application
python app.py
5️⃣ Open in Browser
http://127.0.0.1:5000
